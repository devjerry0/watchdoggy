# Alarm sounds

Put alarm clips in this directory. When the alarm fires, it plays the clip you
selected on the dashboard, or a random one from this directory if you chose
"random". Random selection helps keep the dog from getting used to one sound.

`alert-chirp.wav` is the default. It is two rising sine sweeps (1.4 to 3.7 kHz),
generated by `scripts/gen-beeps.py`:

```sh
python3 scripts/gen-beeps.py                  # regenerate alert-chirp.wav
python3 scripts/gen-beeps.py --variants DIR   # also write alternatives to DIR
```

The variants include a softer chirp, a square-wave chirp, a triple beep, and an
alarm warble.

Notes:

- Supported formats are WAV, FLAC, OGG, and MP3. On Linux, playback goes through
  `pw-play`/`paplay`, so use WAV or FLAC there.
- `deploy-to-pi.sh` doesn't sync this directory, so clips you upload on the Pi
  aren't overwritten. To add sounds on the Pi, upload them from the dashboard
  or copy them into `~/doggy/sounds/`.
- To use a different directory, set `clips_dir` in `settings.json` and restart.
